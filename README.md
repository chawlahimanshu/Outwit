# OUTWIT — Are you smarter?

A daily trivia game. Every day at midnight a new rival appears (a 5th grader, a golden retriever, a pirate…) with 7 type-in questions, 45 seconds each. Faster answers score more points, up to 7,000 a day.

- Single file: `index.html` (no build step, no server)
- 20 rivals in rotation, each with its own pixel-art scene
- Archive of the last 10 days
- Scores and streaks are saved in the player's browser

To add a rival, add an entry to `RIVALS` and a matching scene to `SCENES` in `index.html`.
